# 完整设计

## 服务职责

前台、后台、测速、入口独立部署。业务内容只有一份，公开主页没有 KV 写权限；后台升级不需要把登录代码重新打进两个前台。

| 服务 | 代码 | 绑定 | 职责 |
|---|---|---|---|
| CF 主页 | `worker.mjs` | ASSETS、HOME_BACKEND、PAGE_VIEWS | 静态页面、只读内容/设置/音乐转发、IP、探测；托管原计数 DO |
| 独立后台 | `backend/worker.mjs` | ASSETS、MY_HOME_KV、SITE_SETTINGS、远程 PAGE_VIEWS | 登录、编辑、内容、公开配置、历史和计数接口 |
| CDN | `gateway/worker.mjs` | HOME_BACKEND、GATEWAY_ASSETS | 原版网关页面，后台驱动的文案/线路，背景与头像 |
| 入口 | `entry/worker.mjs` | 无 | 根域首页临时跳转、后台导航 |
| EO Pages | `edge-functions/` | 无私有绑定 | 公共静态镜像、固定后台代理、快照回退 |

入口 Worker 可被跳转规则替代以减少数量；当前代码保持独立，便于单独回滚。后台和两个前台不会因为入口变化而更换数据源。

## 数据模型

- KV `portfolio_data`：个人资料、网站/社区入口、头像与背景等原有内容。
- KV `admin_credentials`：用户名、随机盐、PBKDF2 哈希；无默认可登录密码。
- KV `secret_key`：后台 Cookie 的 HMAC 签名密钥；不公开、不导出。
- `HomepageSettings` SQLite：音乐、视觉、模块、标题、徽章、公告、布局、小票、电脑、页脚、CDN 设置及版本。字段定义与校验在 `public/static/settings-schema.mjs`。
- `PageViewCounter` SQLite：同一个 `homepage` 实例，原子累计页面加载次数，不是独立访客数，不存储访客 IP。

设置用 `expectedVersion` 比较并在同一 SQLite 事务内写入。冲突返回 409；相同设置不产生新版本；最近保留 12 版。恢复先进入草稿，再保存为新版本。

内容和设置属于两种存储，顶部保存按钮依次处理，**不是跨存储事务**。部分失败会保留未保存草稿。保存过程中继续输入的设置也保留，不会被返回的旧提交结果覆盖。

## 请求路径

| 路径 | 后台 | CF | EO |
|---|---|---|---|
| `/manage`、登录/注销 | 管理和登录 | GET 导航到后台；不代理登录 POST | 导航到后台 |
| `/api/data` | GET 公开，POST 登录且同源 | 只读 Service Binding | 只读固定上游，失败用快照 |
| `/api/settings` | GET 公开，POST 登录且同源/版本校验 | 只读 Service Binding | 只读固定上游，失败用快照 |
| `/api/music` | 公开播放配置 | 只读转发 | 只读转发/快照 |
| `/api/settings/history` | 登录后读取列表或指定版本 | 无 | 无 |
| `/api/change-password` | 登录且同源 | 无 | 无 |
| `/api/pageviews` | GET 只读，POST 限指定公开 Origin | 同源检查后转发 | 正式页面浏览器直连后台；保留兼容转发函数，预览只读 |
| `/api/visitor-ip` | 不作为前台回源 | 读取 Cloudflare 可信信息 | 读取 request.eo；缺失时显示暂不可用 |
| `/cdn-check` | 无 | 小 JSON、无计数 | 小 JSON、无计数 |

Cookie 只用于后台，CF/EO 公共转发不携带 Cookie。公开响应无私有凭据。内容、账号、配置写接口拒绝跨站请求，历史接口需要登录。公开计数只用 Origin 限制，不等同于防机器人系统。

## 主页和同步

页面先显示内嵌公开快照，再异步读取配置与内容；上游故障保留已有入口。设置在下次打开/刷新时应用，不中断已播放音乐。访客本地音量/模式优先，默认不自动播放。

模块关闭同时抑制相应音乐、IP、贡献图、计数网络请求。空项目/技能不显示空框。主页面保持直接可见的入口，没有新增公共搜索、分类筛选或顶部导航。

EO 与 CF 必须运行支持统一配置的新版代码；旧 EO 即使能通过探测，也不会自动获得新前端能力。发布前检查 `/cdn-check` 版本和 `/api/settings`，不能只以 HTTP 200 判断代码同步。

## 测速页面

HTML/CSS 直接来自 `cmliu/Blog-CDN-Gateway`；适配层替换头像、背景、站名与标题，并连接已有后台设置。原项目源码和许可原样保留。

浏览器并发 GET 两条 `/cdn-check`，验证状态和 JSON 标记，首个健康响应获选。沿用上游 999ms 跳转等待；手动模式仍检测但不自动跳转，可点击或键盘进入。失败、无 JS 时有可用入口。根域先连通才可能进入测速；这不是解决入口网络不可达的方法。

后台可控制线路名称、启停、超时、自动跳转和文案。背景是本地静态 WebP，原尺寸保留；构建时内嵌头像，不依赖外站头像服务。

## 维护边界

构建不需要私有文件，实际账号配置独立且被忽略。源码、生成的后台页面、图像和许可一起发布。登录凭据、Cookie、账号绑定、部署缓存和机器日志不进入 Git。

不要直接删除托管原访问量 DO 的 CF Worker。新部署先建立它的命名空间，再发布后台和完整前台服务绑定；旧部署保持原迁移历史。

## EO 回源故障处理

如果 EO 接口返回包内快照，浏览器只读回退到后台公开数据、设置和音乐接口；回退也失败时保留快照。计数在正式 EO 域名由浏览器直接向后台发起一次 POST，避免 EO 服务端回源失败影响递增；失败只 GET 回读总数，不重试 POST，防止已提交但响应丢失后重复计数。后台 Origin 白名单不变。

EO 兼容接口不依赖 AbortSignal.timeout，使用可用的 AbortController、原生 EO 超时和总时限；错误只公开稳定分类及 HTTP 状态，不泄露异常堆栈、私有配置或凭据。只读 /api/health 返回连通性与运行时能力布尔值。尚无诊断证据时，不把 EO 回源失败直接认定为 Cloudflare 拦截，也不放宽安全防护。
