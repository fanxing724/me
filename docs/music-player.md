# 音乐管理

日常改歌单在独立后台的“音乐管理”页面操作，不再直接修改静态文件。

## 支持的来源

- 网易云 / QQ：输入数字歌单 ID 或分享链接，选择平台。歌单服务默认使用公开 Meting 接口，可在后台调整。第三方接口与音乐权限可能变化，部分曲目可能只有试听。
- 自定义曲目：歌名、歌手、音频地址、封面、歌词 URL 或内嵌 LRC 文本。支持添加、移除和排序，最多 200 首。

“测试当前歌单”读取的是草稿，可试听，不会发布。保存后两个新版主页刷新即可应用。管理员不需要上传文件；本机音乐功能只让访客在自己的浏览器试听，不上传服务器，刷新后恢复站点歌单。

## 默认值和偏好

后台设置初始音量、默认模式和播放器显隐。访客已经保存在 localStorage 中的音量/模式优先，后台新默认值不会覆盖它们。浏览器要求点击才能播放时，页面给出提示，不强制自动播放。

播放器支持播放/暂停、上下曲、进度、顺序/单曲/随机、歌单弹窗与 LRC。音频和跨域歌词来源需要浏览器能够访问；后台能读到歌单不代表每首都可播放。

## 同步和兜底

`/api/music` 返回后台公开音乐配置。CF 通过 Service Binding 转发，EO 通过固定后台地址转发，均不携带管理员 Cookie。网络失败时使用 `public/music.json` 和部署快照兜底，不会清空保存的设置。
